# Firmware

Código embarcado do controlador. A plataforma (microcontrolador, linguagem, ferramenta
de build) será escolhida na Etapa 2, com registro em `docs/decisoes/`.

Conteúdo previsto:

- `src/` — código fonte.
- `test/` — testes automatizados (unitários e em hardware, quando possível).
- `docs/` — protocolo de comunicação com o software e mapa de pinos.
- `CHANGELOG.md` — versões do firmware.
